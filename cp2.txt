चैप्टर 2 – वेरिएबल्स और डेटा टाइपवेरिएबल क्या है?वेरिएबल एक नाम है, जो मेमोरी के किसी स्थान को प्रोग्राम में देता है।उदाहरण:x = 57    
     # यहाँ x एक वेरिएबल है, जिसमें 57 स्टोर किया गया है।डाटा टाइप्स क्या हैं?Python
 में मुख्य रूप से निम्नलिखित डेटा टाइप्स होते हैं:Integer (पूर्णांक)Floating point numbers (दशमलव संख्या)String (अक्षर/शब्द)Boolean (True/False)None (कोई मान नहीं)Python अपने आप तय करता है कि कौन सा डेटा टाइप है, उसे declare करने की जरूरत नहीं होती।
उदाहरण:a = 44        # a integer टाइप का वेरिएबल है।
b = 44.0      # b floating-point टाइप का वेरिएबल है।
name = "Ram"  # name string टाइप का वेरिएबल है।वेरिएबल का नाम कैसे दें? (रूल्स)वेरिएबल नाम में अक्षर, डिजिट, और अंडरस्कोर ( _ ) आ सकते हैं।नाम की शुरुआत अक्षर या अंडरस्कोर ( _ ) से होनी चाहिए।वेरिएबल नाम की शुरुआत कभी अंक (digit) से नहीं कर सकते।कोई भी नाम Python के रिज़र्व्ड वर्ड (जैसे if, class, etc) नहीं होना चाहिए।उदाहरण:
सही वेरिएबल नाम:harryone8seven_sevenपायथन में ऑप्रेटर (Operators)Arithmetic operators: +, -, *, /, आदिAssignment operators: =, +=, -=, आदिComparison operators: ==, !=, >, <, आदिLogical operators: and, or, notइस गाइड को आप डायरेक्टली कॉपी करके अपने नोट्स या प्रैक्टिकल सेटअप के लिए इस्तेमाल कर सकते हैं।
